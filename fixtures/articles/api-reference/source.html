fetchJSON(url, options)

Fetches the resource at url and parses the response body as JSON. Rejects on a non-2xx status or a body that is not valid JSON.

Parameters

NameTypeDefaultDescription
urlstring—Absolute or relative URL. Relative URLs resolve against document.baseURI.
options.timeoutMsnumber10000Abort the request after this many milliseconds.
options.retriesnumber0Retry count for network errors only, not HTTP errors.

Return value

A Promise that resolves with the parsed value.

Example

const user = await fetchJSON('/api/users/42', { timeoutMs: 2000 });
console.log(user.name);

Errors

  • HttpError — the response status was outside 200–299.
    • error.status holds the numeric code.
  • TimeoutError — the request exceeded timeoutMs.
