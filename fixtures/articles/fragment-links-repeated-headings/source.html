Configuration options

Each subsystem below has its own Options and Examples section. Jump straight to logging options or cache options.

Logging

Options

  • level — one of debug, info, warn, error.
  • json — emit one JSON object per line when true.

Examples

See the cache examples for the matching pattern.

[logging]
level = "info"
json = true

Cache

Options

  • maxEntries — evict least-recently-used past this count.
  • ttlSeconds — hard expiry regardless of use.

Examples

[cache]
maxEntries = 5000
ttlSeconds = 300
