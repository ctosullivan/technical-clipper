# Install

Pick your package manager.

**npm**

```shell
npm install my-lib
```

**pnpm**

```shell
pnpm add my-lib
```

**yarn**

```shell
yarn add my-lib
```

**bun**

```shell
bun add my-lib
```

**deno**

```shell
deno add my-lib
```

Then run the dev server.
