# ai-docs/

Product-capability and evidence-boundary reference material for agents. This
is distinct from:

- `AGENTS.md` (repo root) — the tool-neutral _process_ contract: protocols,
  definition of done, commit conventions.
- `architecture/` — the current + target _technical design_.
- `decisions/` — the historical _why_ behind settled choices.

`ai-docs/` answers a narrower question: **what can this product honestly
claim about a given capture, and what must it never claim?** Start with
[`AGENTS.md`](../AGENTS.md) in this file's directory for that.
